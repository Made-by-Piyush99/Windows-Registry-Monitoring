Questions & Answers

Frequently Asked Questions

Does this replace Windows Defender or my current Antivirus? +
No. Registry Monitor is built to complement your antivirus. Traditional antiviruses scan files on disk, whereas Registry Monitor detects configuration tampering, stealth persistence hooks, and attempts by malware to quietly disable your defenses.
Why are Administrator privileges recommended? +
Standard user accounts can only read and write to HKEY_CURRENT_USER (HKCU). To monitor system-wide services and policies in HKEY_LOCAL_MACHINE (HKLM) and execute 1-click rollbacks, Administrator rights are required.
How does the 1-Click Rollback engine work? +
When an unauthorized registry change is flagged, the Rollback Engine compares the key to its known-good baseline snapshot, prompts the operator for confirmation, and safely restores the original values using atomic Windows registry write transactions.
Is the source code open and auditable? +
Yes! The entire project is open-source and hosted on GitHub under the Made-by-Piyush99 profile with complete documentation, 65 automated tests, and MIT/Defensive licensing.
